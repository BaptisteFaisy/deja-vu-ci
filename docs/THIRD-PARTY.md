# Third-party licences

Déjà-vu CI's runtime dependencies are listed in [`docs/SBOM.json`](SBOM.json)
(generated by `tools/sbom.mjs`). Every runtime dependency is an Atlassian
**Forge SDK** package, plus the three first-party internal packages
(`@dejavu/bridge`, `@dejavu/core`, `@dejavu/present`), which are part of this
repository and covered by its MIT licence — not third party.

The table below lists each **third-party** runtime dependency with its declared
version and licence. Licences are read from the `license` field of each
dependency's own `package.json`; where that field points at a file we also read
it. No licence is invented: a field that is absent is reported as such.

### What "SEE LICENSE IN LICENSE.txt" means

None of the Forge SDK packages is under a permissive licence such as MIT or
Apache-2.0. Their `LICENSE.txt` reads, in substance:

> Permission is hereby granted to use this software in accordance with the terms
> and conditions outlined in the Atlassian Developer Terms, at
> `https://developer.atlassian.com/platform/marketplace/atlassian-developer-terms/`.

In other words, they are licensed for use **with the Atlassian Forge platform
under the Atlassian Developer Terms**, not for arbitrary redistribution. This is
expected: both apps run on Forge, and these packages are provided by the
platform's SDK.

### Which app pulls which package

- **Sensor** (`apps/sensor/package.json`): `@forge/api`, `@forge/bridge`,
  `@forge/kvs`.
- **Brain** (`apps/brain/package.json`): `@forge/api`, `@forge/bridge`,
  `@forge/kvs`, `@forge/events`, `@forge/llm`, `@forge/react`,
  `@forge/resolver`, `@forge/sql`.

The three `@dejavu/*` packages and the two apps have **no `license` field** in
their own manifests; the repository as a whole is MIT (root `package.json`,
`license: "MIT"`), so the first-party code is MIT.

### Methodology and caveats

- Versions are the semver ranges as declared in each `package.json`
  (no lockfile is consulted, no exact resolution is claimed). See
  `docs/SBOM.json`, generated deterministically by `tools/sbom.mjs`.
- Only **runtime** dependencies are listed. Development and toolchain
  dependencies (TypeScript, Vitest, esbuild, React, the fixture scripts) are
  excluded: they never ship inside an app bundle.
- The `@forge/*` `license` field value (`SEE LICENSE IN LICENSE.txt`) is quoted
  verbatim; it is not an SPDX expression, so the "Notes" column states what the
  file actually grants.
